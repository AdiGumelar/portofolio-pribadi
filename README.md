# Portfolio Adi Gumelar

Website portofolio pribadi untuk menampilkan profil, riwayat pendidikan, pengalaman, proyek, pelatihan, keahlian, dan informasi kontak Laurentius Sasmita Adi Gumelar.

## Tampilan dan fitur

- Desain responsif berbasis Bootstrap 5
- Mode terang dan gelap yang tersimpan di browser
- Navigasi _smooth scroll_ dengan penanda menu aktif
- Animasi saat elemen muncul menggunakan AOS
- Loading screen, tombol kembali ke atas, dan animasi teks pada hero section
- Animasi angka statistik serta progress bar keahlian
- Kontak langsung melalui email, WhatsApp, dan lokasi Google Maps

## Teknologi

- HTML5
- CSS3
- JavaScript
- [Bootstrap 5](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- [AOS - Animate On Scroll](https://michalsnik.github.io/aos/)
- Google Fonts (Poppins)

## Struktur proyek

```text
.
|- index.html        # Struktur halaman portofolio
|- css/style.css     # Seluruh gaya dan mode gelap
|- js/script.js      # Interaksi dan animasi halaman
|- Foto New.jpeg     # Foto profil
|- Emoka.png         # Gambar proyek
|- Kapingrejo.png    # Gambar proyek
`- CV - IT.pdf       # Dokumen CV
```

## Menjalankan proyek

Proyek ini berupa website statis sehingga tidak memerlukan instalasi dependensi.

1. Clone atau unduh repositori ini.
2. Buka file `index.html` di browser.

Untuk pengalaman pengembangan yang lebih nyaman, jalankan proyek melalui _Live Server_ pada VS Code atau web server lokal seperti Laragon.

## Kustomisasi

- Ubah konten portofolio melalui `index.html`.
- Sesuaikan warna, tata letak, dan responsivitas melalui `css/style.css`.
- Atur perilaku interaktif melalui `js/script.js`.
- Ganti aset gambar atau CV dengan file milik Anda dan sesuaikan path-nya pada `index.html`.
